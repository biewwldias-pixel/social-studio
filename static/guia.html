Como conseguir todas as variáveis

Passo a passo completo para configurar a IA, publicar direto no Instagram e conectar seus projetos locais. Todas as credenciais ficam salvas apenas no seu computador.

Prefere que sua IA te guie passo a passo?

Copie o prompt abaixo e cole no ChatGPT, Claude, Gemini ou Antigravity para configurar tudo em poucos minutos. 

Quero configurar o aplicativo local **Social Studio** (que cria e publica posts, carrosséis e stories no Instagram usando IA).

Me guie passo a passo, uma etapa por vez, esperando eu confirmar antes de avançar, para conseguir e preencher todas estas credenciais na interface do app (botão ⚙):

1. **Chave da IA (aba ⚙ → IA & R2):**
   - `GEMINI_API_KEY`: como gerar gratuitamente no Google AI Studio (aistudio.google.com/apikey).

2. **Ponte temporária de imagens — Cloudflare R2 (aba ⚙ → IA & R2):**
   *(A Meta Graph API exige URL pública HTTPS para baixar as imagens antes de publicar; o Social Studio envia e apaga logo depois.)*
   - `R2_CLOUDFLARE_ENDPOINT_DEFAULT` (ex.: `https://.r2.cloudflarestorage.com`)
   - `R2_CLOUDFLARE_PUBLIC_URL` (URL pública `r2.dev` ou domínio customizado do bucket)
   - `R2_CLOUDFLARE_ACCESS_KEY_ID`
   - `R2_CLOUDFLARE_SECRET_ACCESS_KEY`
   - `R2_BUCKET` (nome do bucket criado no R2)

3. **Conta do Instagram — Meta Graph API (aba ⚙ → Perfil do projeto):**
   - Garantir que o Instagram é conta Profissional (Comercial ou Criador) vinculada a uma Página do Facebook.
   - Criar um App no Meta for Developers (developers.facebook.com) e um Usuário do Sistema (System User) no Business Manager para gerar um **Access Token permanente** (que não expira) com as permissões `instagram_basic`, `instagram_content_publish`, `pages_show_list` e `pages_read_engagement`.
   - Descobrir o `Instagram Account ID` correto chamando `GET https://graph.facebook.com/v22.0/me/accounts?fields=id,name,instagram_business_account{id,username}` com o token gerado.

4. **Conectar o projeto local (aba ⚙ → +):**
   - Criar um perfil com o nome do projeto, escolher a pasta local pelo botão `Procurar...` e clicar em `✨ Entender Design` para o agente ler cores, tipografia e posts antigos automaticamente.

1

Chave da IA (Gemini)

⚙ → IA & R2
  1. Acesse aistudio.google.com/apikey e faça login com sua conta Google.
  2. Clique em Create API key e copie a chave gerada (começa com AIza...).
  3. No Social Studio, abra ⚙ → IA & R2, cole em GEMINI_API_KEY e clique em Salvar.
GEMINI_API_KEY Usada pelo agente para criar artes, legendas e executar ✨ Entender Design
2

Ponte Temporária de Imagem (Cloudflare R2)

⚙ → IA & R2
Por que isso existe? A API oficial do Instagram não aceita upload direto de arquivo local — ela exige uma URL pública HTTPS. O Social Studio sobe o JPEG por alguns segundos no seu R2 (plano gratuito) e apaga automaticamente assim que o Instagram confirma.
  1. Acesse dash.cloudflare.com → R2 Object Storage → clique em Create bucket (ex.: social-studio-media).
  2. Dentro do bucket, abra Settings → Public Development URL, habilite o acesso público e copie a URL https://pub-xxxx.r2.dev.
  3. Na página principal do R2, clique em Manage R2 API Tokens → Create API token com permissão Object Read & Write no seu bucket.
  4. Copie o Endpoint S3, o Access Key ID e o Secret Access Key para ⚙ → IA & R2.
R2_CLOUDFLARE_ENDPOINT_DEFAULT Ex.: https://<ACCOUNT_ID>.r2.cloudflarestorage.com
R2_CLOUDFLARE_PUBLIC_URL Ex.: https://pub-xxxx.r2.dev
R2_CLOUDFLARE_ACCESS_KEY_ID Chave S3 do token R2
R2_CLOUDFLARE_SECRET_ACCESS_KEY Segredo S3 do token R2
3

Conta do Instagram (Meta Graph API)

⚙ → Aba do Perfil
  1. No celular, confirme que sua conta do Instagram está como Profissional (Comercial ou Criador) e vinculada a uma Página do Facebook.
  2. Acesse developers.facebook.com e crie um aplicativo do tipo Business vinculado ao seu Portfólio Empresarial.
  3. No Business Manager → Usuários do Sistema, crie um usuário (ex.: social-studio), atribua a ele a Página do Facebook e o App criado.
  4. Clique em Gerar novo token com expiração Nunca marcando: instagram_basic, instagram_content_publish, pages_show_list e pages_read_engagement. Esse é o seu Access Token.
  5. Para pegar o Instagram Account ID exato, consulte sua Página usando o token no Graph API Explorer com o endpoint: me/accounts?fields=id,name,instagram_business_account{id,username} — use o campo instagram_business_account.id.
Instagram Account ID ID numérico retornado em instagram_business_account.id
Access Token Token permanente do System User (começa com EAA...)
4

Adicionar seu Projeto & Entender Design

⚙ → +
  1. Abra ⚙ e clique na aba + (primeira aba à esquerda).
  2. Dê um nome ao perfil, clique em Procurar... para escolher a pasta do seu código local e clique em Criar perfil.
  3. Dentro do perfil recém-criado, clique em ✨ Entender Design: o agente vai ler CSS, cores, fontes e posts antigos do projeto e gerar automaticamente o guia em Markdown.
